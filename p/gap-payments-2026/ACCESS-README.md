# GAP / Vpayments — ιδιωτική σελίδα πρότασης

URL: https://inframind.eu/p/gap-payments-2026/

## Πώς προστατεύεται

Ο έλεγχος γίνεται **στον διακομιστή**, από το `netlify/edge-functions/gate.ts`.
Καλύπτει όλο τον φάκελο — και το `index.html` και τα δύο PDF. Χωρίς έγκυρη
συνεδρία το Netlify δεν στέλνει κανένα byte περιεχομένου (HTTP 401).

Δεν υπάρχει κωδικός μέσα στον κώδικα. Μόνο SHA-256 hashes, σε μεταβλητές
περιβάλλοντος του Netlify:

| Μεταβλητή        | Τι είναι                                            |
|------------------|-----------------------------------------------------|
| `GAP_PW_HASH`    | SHA-256 του κωδικού που δίνεται στον παραλήπτη       |
| `GAP_ADMIN_HASH` | SHA-256 του δικού σου κλειδιού για τη σελίδα insights |
| `GAP_SECRET`     | τυχαίο κλειδί υπογραφής των cookies συνεδρίας         |

**Προσοχή:** οι μεταβλητές διαβάζονται κατά το deploy. Αν αλλάξεις κάποια,
χρειάζεται νέο deploy (π.χ. `git commit --allow-empty -m "redeploy" && git push`).

## Αλλαγή κωδικού

```
echo -n 'ΝΕΟΣ-ΚΩΔΙΚΟΣ' | shasum -a 256
```
Βάλε το hex στο `GAP_PW_HASH` (Netlify → Site configuration → Environment variables)
και κάνε ένα redeploy.

## Λήξη ισχύος

Ορίζεται στο `VALID_UNTIL` στο `gate.ts` (τώρα: 10 Οκτωβρίου 2026, 23:59 Κύπρου).
Μετά την ημερομηνία η σελίδα επιστρέφει 410 με μήνυμα λήξης.

## Καταγραφή πρόσβασης

- `https://inframind.eu/_im/insights?k=<GAP_ADMIN_KEY>` — πίνακας με είσοδοι,
  ανοίγματα εγγράφων, χρόνος ανάγνωσης, επισκέψεις inframind.eu.
- Χωρίς σωστό `k` επιστρέφει 404.
- Κάθε συμβάν γράφεται και ως `GAPLOG {...}` στα Netlify function logs (εφεδρεία).

## Τι **δεν** καλύπτει

Τα PDF βρίσκονται και μέσα στο δημόσιο repo στο GitHub. Το gate προστατεύει το
inframind.eu, όχι το GitHub. Για πλήρη απομόνωση: μεταφορά των αρχείων σε
Netlify Blobs και σερβίρισμα μόνο μέσω της edge function (επόμενη φάση).
